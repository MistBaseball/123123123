검증 스크립트: `Validation/verify_numeric.py` (Python 3 + NumPy 필요).

## 여기에서 실행하지 못한 검사

- 사용자의 실제 Unity 6000.6.1f1 프로젝트 컴파일.
- 실제 URP 렌더링 및 화면 배치.
- Windows 마우스/키보드 입력과 Game View 포커스.
- 자동 씬 생성 메뉴 실행 및 Unity 직렬화 결과.
- Unity 에디터 내 C# 자동 검사 메뉴 실행.
- Play Mode의 조준, 발사, 자동 복귀, R 초기화, 창 전환.
- 플레이어 빌드 및 모바일 동작.

이 환경에는 사용자의 Unity 프로젝트와 연결된 Unity Editor/MCP, Unity 실행 파일, C# 컴파일러가 없다. 따라서 “Unity에서 정상 실행 확인 완료”로 표시하지 않는다.

## Unity에서 제공되는 추가 검사

`Tools > Baseball MVP > 2. Run Math and Scene Checks`는 실제 C# 함수와 임시 Unity 컴포넌트를 검사한다. 기본 생성 씬에서 모든 항목이 통과하면 924 checks가 예상된다. 이 숫자는 **제공한 테스트의 예상 항목 수**이며, 여기에서 924개를 실행했다는 뜻이 아니다.

검사 완료 후 `README_KO.md`의 16개 수동 플레이 테스트를 실행한다. 게임 플레이 MVP의 최종 승인 기준은 다음과 같다.

1. 새로운 빨간 Console 오류 없음.
2. 유효 영역 안의 서로 다른 3개 클릭 지점에 각각 도착.
3. 보정 전 Error < 1mm.
4. 비행 중 마우스 이동으로 목표점이 변하지 않음.
5. 연타/버튼 유지로 중복 투구하지 않음.
6. R 초기화와 자동 준비가 정상 동작.
7. 기존 PitchingPrototype 씬이 그대로 남아 있음.
