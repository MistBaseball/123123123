# 목표와 다음 작업

이는 인수인계용 계획이다. 아래 모든 기능을 한 번에 추가하라는 승인이 아니다. 사용자가 다음 작업을 정하면 해당 범위만 구현한다.

## 가장 가까운 순서

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| 0 | 현재 독립 웹 실행 확인 + 사용자의 실제 Unity 프로젝트 확인 | 웹 검사/빌드 통과, Unity 버전·패키지·씬·Console 증거 확보 |
| 1 | Unity 클릭 투구 패키지 설치 상태 검증 | 생성/검사 메뉴와 직접 입력 체크리스트 통과, 중복 공 이동 제거 여부 확인 |
| 2 | Unity에 제구와 4구종, 동일 데이터 기반 움직임 표시 | 클릭 목표 고정, 구종별 도착·휨 검증, Inspector·HUD 안내 |
| 3 | 타자 AI·타격·타구 이동의 최소 루프 | 투구→판정→타구→종료가 반복 가능, 물리 이동 소유자 하나 |
| 4 | 개별 Runner 데이터와 베이스 순환, 수비 역할 분담 | 주자 신원/속도 지속, 렌더·규칙 공유, 포스/태그/플라이 회귀 검사 |
| 5 | 한 이닝→9이닝, 피로·기록·저장 | 공수 교대·끝내기·세 번째 아웃 득점·경기 종료 한 번 검증 |
| 6 | 고교 육성·일정·스카우트 | 생성/주사위·훈련·대회·진로의 한 시즌 연결 |
| 7 | 장기 커리어와 추가 콘텐츠 | 프로·계약·부상·이적·특수 구종 등을 작은 기능 단위로 확장 |

웹 유지보수는 별도다. 눈앞의 버그는 웹에서 고치고 테스트를 남기되, 엔진을 무작정 여러 파일로 나누거나 완전히 다시 쓰지 않는다. 전체 공 물리/수비 Coordinator/영속 Runner 도입은 자료형과 규칙이 함께 바뀌므로 먼저 범위를 합의한다.
