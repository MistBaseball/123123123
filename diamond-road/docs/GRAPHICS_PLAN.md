# 사실적인 그래픽 개선 — 진행 메모

시작: 2026-10-01. 대상: 웹 3D 렌더러 `web/lib/game/field.ts` (Three.js). 게임 규칙(`engine.ts`)과 좌표는 바꾸지 않는다.
작업이 중간에 끊기면 이 파일의 체크 상태와 마지막 커밋부터 이어서 한다.

## 원칙

- 외부 이미지·모델 파일 없이 코드로 만든 텍스처(캔버스)와 Three.js 도형만 쓴다. 저작권 문제·다운로드 없음.
- 저사양 노트북(i7-1165G7 / Iris Xe)에서도 돌아가야 한다. 후처리(포스트 프로세싱) 없이 조명·재질·텍스처로 품질을 올린다.
- `Figure` 구조(root/left/right/legL/legR/bat)는 유지한다. 애니메이션 코드가 그대로 동작해야 한다.
- 각 단계가 끝날 때마다 `npm test`·빌드·화면 캡처 확인 후 커밋·푸시하고 `game/` 빌드를 갱신한다.

## 단계

- [x] 1. 하늘·조명: 그라데이션 하늘, 오후 햇빛 색과 그림자, 안개, 노출
- [x] 2. 그라운드: 잔디 결(잔디 깎은 줄무늬)·흙 질감 텍스처, 굵기 있는 흰 라인, 마운드·홈플레이트·베이스 모양
- [x] 3. 선수: 비율 맞춘 몸, 유니폼(상의·바지·스타킹·벨트·등번호), 모자 챙, 글러브, 헬멧, 신발
- [x] 4. 경기장: 외야 펜스 패딩, 관중석 좌석 층, 조명탑 램프, 전광판, 관중 다양화
- [x] 5. 마무리: 공 실밥 텍스처, 성능 확인, 문서 갱신

## 진행 기록

(단계마다 한 줄씩 추가)

- 1·2단계 완료: `textures.ts`(하늘·잔디·흙·패딩·좌석·공·유니폼 텍스처 함수) 추가. 하늘 돔, 낮은 오후 햇빛+보조광, 잔디 한 장(깎은 줄무늬)+잎 범프, 29 m 내야 흙 호와 잔디 사각형, 베이스 컷아웃, 워닝 트랙, 마운드, 흰 베이스, 홈플레이트, 폭 있는 라인·타석 박스.
- 3단계 완료: `figure()` 재작성. 1.85 m 비율, 등번호 유니폼(몸통만), 바지·스타킹·벨트, 모자 챙/타자 헬멧, 글러브, 스파이크, 피부색 4종. 좌타자 좌우 반전 시 등번호 텍스처를 되돌린다(`Figure.jersey`).
- 4단계 완료: `makeStadium()` 추가. 한 장으로 이어진 외야 패딩 펜스+노란 홈런 라인, 홈 뒤를 감싸는 계단식 관중석(Lathe, 18단)과 외야 관중석(12단), 관중 약 4천 명(InstancedMesh), 백스톱 간판, 전광판, 램프가 빛나는 조명탑 4개. 중계 카메라 앞을 가리던 조명탑은 옮겼다.
- 5단계 완료: 실밥 텍스처 공(비행 중 회전), 관중을 6각 기둥으로 바꿔 삼각형 58만→18~21만, 드로우콜 375(투수 시점)~568(중계). 클라우드 테스트 브라우저는 그래픽카드가 없어 실제 FPS는 측정하지 못함. 호환 렌더러(`software-field.ts`)는 이번 작업 대상이 아니라 그대로다.
